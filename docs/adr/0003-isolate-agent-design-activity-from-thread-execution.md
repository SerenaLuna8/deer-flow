# Isolate Agent Design activity from Thread execution

Agent Builder remains an owner-private Agent Design Session using its existing no-tool one-shot generation rather than becoming a Thread or Run. Real-time reasoning and verified design stages are recorded in a dedicated append-only Agent Design Activity stream with its own private scope, cursor, replay, SSE ownership, and frontend cache root; generic cursor, batching, SSE, mode-selection, and presentation primitives may be shared, but ordinary Thread history, Run events, stream state, and cache keys are not. Reasoning within the selected model's configured output budget is retained without an additional small display cap, while crossing the platform's absolute safety ceiling stops the turn with an explicit terminal outcome instead of silently truncating it. This preserves chat behavior and authority isolation at the cost of a separate Builder activity projection and recovery path.
