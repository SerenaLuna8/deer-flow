# 创建你的第一个 Harness

本教程介绍如何以编程方式使用 ActWeave Harness Python SDK——直接在你的 Python 代码中导入和使用 ActWeave，而不是通过 Web 界面。

## 前置条件

- Python 3.12+
- 已安装 `uv`
- 已克隆 ActWeave 仓库

## 安装

```bash
cd deer-flow/backend
uv sync
```

<Callout type="info">
  完整 ActWeave 应用会把模型定义和模型自有的加密 API Key 存入 PostgreSQL 系统设置。
  下面的底层 SDK 示例仅直接构造一个内存中的 LangChain 模型实例，不会创建或持久化
  应用模型定义。
</Callout>

## 编写代码

创建 `my_agent.py`：

```python
from getpass import getpass

from deerflow.agents import create_deerflow_agent
from langchain_openai import ChatOpenAI
from pydantic import SecretStr

model = ChatOpenAI(
    model="gpt-4o",
    api_key=SecretStr(getpass("OpenAI API key: ")),
)
agent = create_deerflow_agent(model)

for event in agent.stream(
    {
        "messages": [
            {
                "role": "user",
                "content": "用 Python 写一个斐波那契数列函数，包含文档字符串",
            }
        ]
    },
    stream_mode=["messages", "values"],
):
    print(event)
```

## 运行

```bash
cd backend
uv run python my_agent.py
```
