# 使用记忆系统

1. 进入项目并开始对话，明确表达需要长期保留的偏好或纠正。
2. 需要归档较早的完整轮次时使用 `/compact`；可见聊天记录不会改变。
3. 使用 `/Dream` 先压缩当前 Thread 再整理待处理 Memory，或打开 **Memory** 并点击“立即整理”。
4. 在 Memory 页面查看当前文档、待整理数量、已保存版本和每次真实 diff。
5. 使用 `/dream-log [version]` 直接打开指定版本；使用 `/dream-restore <version>` 或“恢复此版本”，确认后把历史内容写成新的当前版本。
6. 在“设置 → 个性化”中，关闭 Memory 只暂停学习、Dream 和召回，数据仍保留；重置会永久删除长期 Memory，但保留聊天和 `/compact` 摘要。

平台管理员还可以在 **Admin → 系统设置 → Memory** 中配置 2～8 个文档章节标题。请在新作用域首次产生 Memory 文档前完成配置；修改只影响之后新建的文档，已有文档保持原章节。

Memory 按认证用户和项目隔离。这些斜杠命令由产品明确处理，不会作为普通消息发送给 Agent。
