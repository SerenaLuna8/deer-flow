# 运维与排障

统一浏览器入口是 `http://localhost:2026`。Gateway 负责 API 准入和 SSE 读取，Worker 执行 Agent job，Scheduler 仅在启用时拥有 Automation 轮询。

```bash
make doctor
make check-db
make support-bundle
```

Run 长时间 queued 时检查 Worker readiness 和 job 状态；Automation 未触发时检查 Scheduler enabled 状态与 advisory-lock ownership；SSE 重连失败时确认 cursor 仍绑定同一 account/project/thread。

项目私有数据和 Memory 均由 PostgreSQL 持久化。不要通过创建本地私有数据文件修复问题。
