# Fluva 应用

<Callout type="info">
  Fluva 应用是构建在 Fluva Harness 之上的多账户、多项目 Super Agent 系统。Gateway 准入工作，只有 Worker 执行 Agent graph。
</Callout>

## 核心能力

| 能力 | 描述 |
| --- | --- |
| 项目工作区 | 项目、成员、邀请、角色、配额、审计和生命周期 |
| 私有工作 | 持久化 Thread、Run、上传、Artifact、Feedback 和 durable SSE |
| 治理资产 | System/Project Agent、Skill、MCP、binding 和准入 snapshot |
| Agent harness | Sub-Agent、Memory、Plan Mode、上下文压缩、Guardrail 和 Sandbox |
| Automation | Scheduler 准入一次性或 Cron occurrence，Worker 执行 |
| IM Connection | 复用相同项目准入边界的项目绑定渠道连接 |

## 架构

```text
Browser / IM
     │
     ▼
Nginx :2026 ─────► Frontend :3000
     │
     └───────────► Gateway :8001 ─────► PostgreSQL
                                      ▲          ▲
                                      │          │
                                  Worker     Scheduler
```

- Nginx 是唯一对外入口。
- Frontend 负责界面，不是授权权威。
- Gateway 负责认证、项目授权、Run 准入、查询和 SSE replay，永不执行 Agent graph。
- Worker 租约领取 PostgreSQL job，是唯一 Agent graph executor。
- Scheduler 可选准入到期 Automation，不执行 graph code。
- PostgreSQL 保存应用数据、checkpoint、job、stream、quota、audit 和版本化资产 snapshot。

私有资源始终绑定 account、project、membership 与 owner context。隔离由业务层和数据库模型保证，不使用 PostgreSQL RLS。
