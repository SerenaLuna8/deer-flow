# 技能

Skill 是包含指令和资源的版本化能力包。system admin 发布系统 Skill，项目成员创建项目 Skill 或 binding 允许的系统版本。

Gateway 在 Run 准入时固定 exact enabled Skill version。Worker 只把这些 bytes materialize 到 sandbox，Agent 再按需渐进加载。本地 custom 目录不是生产 catalog。

在项目设置中创建、版本化、启用和 binding Skill。变更只影响后续准入，不会改变已经 admitted 的 Run。
