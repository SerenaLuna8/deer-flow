# 记忆系统

Memory 把结构化上下文摘要和事实存入明确的 project、owner、namespace。读取、写入、队列项和 prompt 注入始终携带相同 authority 坐标。

admitted private Run 结束后，异步 Memory middleware 过滤可见用户消息和最终助手回复，并进入项目队列。处理前重新验证 membership；updater 读取 PostgreSQL snapshot，通过乐观版本更新，并为新事实记录来源 Thread/Run。

没有可信项目 scope 的运行不会读取、注入或持久化 Memory；同步 middleware hook 同样失败关闭。

项目成员按 capability 在项目 Memory 页面管理内容。导入、清理和 fact mutation 都使用认证项目 API。
