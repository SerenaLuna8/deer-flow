## ActWeave 1.0

ActWeave 1.0 是项目优先 Agent 平台的首个公开版本。它把浏览器工作区、持久化
Agent 执行、受治理的项目资产、PostgreSQL 状态以及显式选择的执行 Provider
整合为一套完整系统。

### 首个版本包含什么

- 项目级 Agent、Skill、MCP 连接、Credential、Memory 与 Automation，并由服务端
  强制执行权限边界。
- 可恢复事件流、checkpoint 和仅由 Worker 执行的持久化 Run。
- 版本化资产与不可变 Run 快照，使重试继续使用准入时的精确配置。
- Local、AIO 及其他已配置执行 Provider；隔离边界明确，失败时不会静默回退宿主机。

### Local 本机命令精确审批

明确使用 `LocalSandboxProvider` 的部署可以要求每条 Bash 命令单次审批。允许只授权
这一条命令启动，下一条命令必须重新决定；拒绝或审批过期时，进程不会启动。

审批不会把 Local Provider 变成沙箱。选定隔离 Provider 的命令在对应环境中执行，
不进入 Local 审批流程，隔离失败时也不会回退为 Local 执行。

本次发布是产品的 v1 基线。应用包统一使用 `1.0.0`；配置和数据库后续分别按照各自
明确的兼容性契约演进。
