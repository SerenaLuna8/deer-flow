# Skills

A Skill is a versioned capability package containing instructions and resources. System admins publish system Skills; project members create project Skills or bind allowed system versions.

At Run admission, Gateway freezes the exact enabled Skill versions. Worker materializes only those bytes into the sandbox and the agent loads them progressively. Local custom directories are not a production catalog.

Use project settings to create, version, enable and bind Skills. Changes affect later admissions and never mutate an already-admitted Run.
