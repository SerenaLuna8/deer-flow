# Operations and Troubleshooting

Use the unified browser entry at `http://localhost:2026`. Gateway handles API admission and SSE reads, Worker executes Agent jobs, and Scheduler owns Automation polling only when enabled.

```bash
make doctor
make check-db
make support-bundle
```

If runs remain queued, inspect Worker readiness and job state. If Automation does not fire, inspect Scheduler enabled state and advisory-lock ownership. If SSE reconnect fails, verify the durable stream cursor remains under the same account/project/thread.

Project private data and Memory are PostgreSQL-backed. Do not repair missing data by creating local private-data files. Backup/restore uses authenticated encrypted archives, external tombstone journals and a new target database.

Support bundles are redacted, but should still be shared only with trusted maintainers.
