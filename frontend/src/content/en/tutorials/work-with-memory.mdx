# Work with Memory

1. Enter a project and open **Memory**.
2. Confirm project readiness and your Memory capability.
3. Start a project conversation and state a durable preference or correction.
4. After the Run finishes, refresh the Memory page to inspect the structured fact.
5. Edit, import or clear Memory only from the same project context.

Memory is isolated by project and owner. A conversation outside an authenticated project cannot read or update it.
